    What this cannot say

    A gap between Polymarket and a CME-method bin is not a trade. A raw NegRisk sum is not an edge until every outcome is on the book. The depth walk reads visible bids and asks once per snapshot, and legs do not fill atomically; a set that passes is not a fill you can count on, and a set that fails any leg is rejected, not partly filled. Two freeze days are not a win rate. This page is a receipt, not a signal shop.
